# Avani M U — Modern Portfolio

A modern, responsive static portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — portfolio content
- `style.css` — responsive design system
- `script.js` — mobile navigation + active-section highlighting
- `README.md` — setup notes

## Run locally
Open `index.html` directly, or run:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Before publishing
Replace the bracketed placeholders in `index.html` with your actual:
- GitHub / LinkedIn / email
- resume PDF
- project names, links and details
- internship dates and responsibilities
- freelance project details
- leadership details
- real photos

The redesign keeps the original content structure but uses a modern editorial/bento visual system, responsive cards, stronger hierarchy, sticky navigation, and mobile-friendly layouts.
